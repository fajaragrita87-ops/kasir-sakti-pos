1. Pendahuluan

1.1 Tujuan Dokumen

Dokumen ini merupakan Spesifikasi Kebutuhan Perangkat Lunak (SKPL) untuk sistem Kasir Sakti POS versi 2.0 Enterprise. Dokumen ini mendeskripsikan kebutuhan fungsional, non-fungsional, arsitektur sistem, dan model bisnis platform secara menyeluruh.

1.2 Ruang Lingkup

Kasir Sakti POS adalah platform SaaS (Software as a Service) berbasis web yang menyediakan solusi Point of Sale modern untuk bisnis ritel dan food & beverage di Indonesia. Sistem mencakup:

  • Transaksi kasir real-time dengan berbagai metode pembayaran
  • Manajemen inventori, resep, dan bahan baku
  • Sistem HRD, absensi, dan payroll karyawan
  • Akuntansi terintegrasi dan laporan keuangan
  • Program loyalitas pelanggan multi-tier
  • Kitchen Display System (KDS)
  • Integrasi pesanan online (GoFood, GrabFood, WhatsApp)
  • Sistem Anti-Antri berbasis QR Code
  • Monetisasi berbasis Koin (Pay-As-You-Go)

2. Deskripsi Umum Sistem

2.1 Perspektif Produk

Kasir Sakti POS diposisikan sebagai alternatif premium berbiaya rendah terhadap kompetitor seperti Moka POS, iSeller, dan Majoo. Model PAYG berbasis Koin memastikan merchant hanya membayar fitur yang benar-benar mereka gunakan, sedangkan core kasir (transaksi dasar) tersedia gratis selamanya.

2.2 Fungsi Utama Sistem

  • Memproses transaksi penjualan secara cepat dan akurat
  • Mengelola stok produk secara real-time dengan dukungan BOM/Resep
  • Menyediakan laporan keuangan dan analitik bisnis komprehensif
  • Mengotomasi penggajian karyawan sesuai perundangan Indonesia
  • Mengintegrasikan pesanan dari berbagai platform online ke satu dashboard
  • Menyediakan infrastruktur multi-tenant untuk ribuan merchant

4. Kebutuhan Fungsional

4.1 Modul POS (Kasir)

  • Pencarian produk by nama / SKU / barcode
  • Manajemen keranjang: tambah, kurang, hapus item
  • Diskon per item atau total transaksi (nominal/persen)
  • Metode pembayaran: Tunai, QRIS, Kartu Debit, Piutang
  • Kembalian otomatis untuk pembayaran tunai
  • Struk digital (print / WhatsApp)
  • Catatan audit transaksi (void, diskon) secara otomatis

4.2 Modul Inventori & Resep

  • CRUD produk dengan foto, SKU, kategori, satuan
  • Sistem BOM/Resep: stok bahan baku berkurang otomatis saat produk terjual
  • Alert stok menipis dan habis secara real-time
  • Kalkulasi margin keuntungan otomatis (HPP vs. Harga Jual)
  • Manajemen kategori dinamis (tambah/hapus/rename)

4.3 Modul HRD & Payroll

  • Registrasi karyawan dengan data lengkap (nama, jabatan, gaji, rekening, BPJS)
  • Absensi selfie + GPS real-time (anti-cheat)
  • Kalkulasi payroll otomatis: gaji pokok + tunjangan + lembur − BPJS (UU Cipta Kerja No.6/2023)
  • Perhitungan BPJS Kesehatan (1% karyawan, 4% perusahaan) & Ketenagakerjaan (PP 44/2015)
  • Manajemen Izin, Sakit, Cuti dengan approval flow
  • Jadwal Shift mingguan
  • Kalkulator THR otomatis (UU Ketenagakerjaan Pasal 79)
  • Export slip gaji / kirim via WhatsApp

4.4 Modul Akuntansi

  • Jurnal manual: Pengeluaran, Pemasukan, Transfer Kas dengan double-entry otomatis
  • Kategori akun kustom (user dapat membuat kategori sendiri)
  • Manajemen Aset Tetap dengan kalkulasi penyusutan otomatis
  • Laporan: Laba Rugi, Neraca, Arus Kas, Buku Besar, Perubahan Modal
  • Export laporan ke PDF / Excel

4.5 Modul Loyalty Program

  • Sistem poin otomatis per transaksi
  • 4 Tier: Bronze, Silver, Gold, Platinum
  • Penukaran poin menjadi voucher diskon
  • Analisis RFM (Recency, Frequency, Monetary) pelanggan
  • Notifikasi poin ke pelanggan (WhatsApp)

4.6 Kitchen Display System (KDS)

  • Tampilan Kanban Board pesanan dapur real-time
  • Status: Antri → Masak → Siap → Selesai
  • SLA Timer dengan peringatan keterlambatan
  • Sinkronisasi instan dari kasir

4.7 Modul Pesanan Online & Reservasi

  • Integrasi GoFood, GrabFood, WhatsApp Order, Reservasi langsung
  • Notifikasi real-time dengan suara berbeda per platform
  • Dashboard terpusat semua saluran pesanan
  • Manajemen reservasi meja/jadwal

4.8 Sistem Anti-Antri (QR Table)

  • QR Code unik per meja / area
  • Pelanggan scan → tampil menu digital → pesan → bayar mandiri
  • Pesanan masuk otomatis ke kasir dan KDS

4.9 Sistem Koin & Billing (PAYG)

  • Koin sebagai mata uang aktivasi fitur
  • Setiap fitur tersedia dalam paket Harian (1 koin), Mingguan (6 koin), Bulanan (27 koin)
  • KDS khusus bulanan (28 koin)
  • Countdown real-time masa berlaku fitur
  • Histori transaksi koin lengkap

6. Arsitektur & Teknologi

6.1 Frontend

  • Framework: React 18 (TypeScript)
  • Styling: Tailwind CSS v3
  • State Management: Zustand
  • Routing: React Router v6
  • Icons: Lucide React
  • PWA: Service Worker + Web Manifest
  • Build Tool: Vite

6.2 Backend

  • Runtime: Node.js (Express / Fastify)
  • ORM: Prisma ORM
  • Database: PostgreSQL
  • Auth: JWT (Access + Refresh Token)
  • File Storage: Cloudinary / AWS S3

6.3 Infrastruktur

  • Deployment: Vercel (Frontend) + Railway/Render (Backend)
  • CI/CD: GitHub Actions
  • Monitoring: Sentry (Error Tracking)

9. Alur Sistem Utama

9.1 Alur Transaksi POS

  1. Kasir login → Buka menu POS
  2. Pilih produk → Masuk keranjang → Stok dicek real-time
  3. Terapkan diskon (opsional) → Pilih metode bayar
  4. Konfirmasi pembayaran → Struk dicetak / dikirim WA
  5. Stok produk (dan bahan baku jika BOM) berkurang otomatis
  6. Data transaksi masuk ke laporan akuntansi & audit log

9.2 Alur Aktivasi Fitur Premium

  1. Owner buka Pengaturan → App Market
  2. Pilih modul → Pilih durasi (Harian/Mingguan/Bulanan)
  3. Sistem debit Koin sesuai harga
  4. Menu fitur langsung muncul di sidebar dalam 5 detik
  5. Countdown timer berjalan real-time hingga masa berlaku habis
